# Notely

Notely is a workspace for organizing ideas, taking notes, and managing projects. It uses Clerk authentication and Convex real-time synchronization to keep your canvases available across devices.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Clerk
- Convex
- BlockNote
- EdgeStore

## Run Locally

Install the dependencies, then run these commands in separate terminals:

```bash
npm install
npx convex dev
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
